# Review and accept evidence

1. Select a project or the owner-only group scope. Enter a classified draft with evidence and provenance. Unknown results stay unknown.
2. Check title/body/structured register fields. Update the draft; every successful edit creates a new version. A stale edit must be reloaded rather than overwrite another edit.
3. Use Red Team as a review role: challenge demand, economics, operational feasibility, claims and hard stops. Record objections as evidence, not as a claim that an agent independently verified them.
4. Assemble the Investment Committee recommendation with downside, alternatives and exact next action. No AI committee is running automatically.
5. Request acceptance on the exact record version. The owner reviews the exact payload, approves with MFA, then executes. Expired/stale/consumed approval requests cannot be reused.
6. Accepted records are immutable. New contradictory evidence is a new record; a future supersession workflow will link the change. Do not delete the accepted history.

Record acceptance is not permission to spend, publish, trade or deploy. Those external executors are disabled.
