## Scope

Base: `3c6907e25f8a03228e6c119f11988cc0c12fb082`. The accepted checkout remains unchanged. This isolated candidate adds a read-only inbox at the exact `/os/enquiries` route. Owners can filter recorded status and form type, browse 25 rows per page, open an older submission, and return to the same filter/page context. There is no free-text or contact search in URLs. Pages are bounded to 1,000,000 and malformed or duplicate relevant parameters fail closed. A selected detail preserves the existing `public-enquiry-ID` fragment target.

No triage state is changed, no response is sent, and no website content is published.
