## Local contract

`packages/integration/local-orchestration.sql` is an unnumbered fixture extension installed after canonical 119 and all four connector/custom-app proposal files. It is never discovered as a hosted migration. A fresh-only installer checks exact added table and function names and captures complete canonical/installed catalogues. Existing lane scripts, tests, UI, production selectors, and corrected paired resolver remain preserved.

A human owner creates a five-minute-or-shorter delegation for one approved paired task and one existing fake GitHub connection. A device needs both its paired session and the independently generated delegation token. Each transaction rechecks server-resolved identity, account/session, tenant, room, sources, task state/fence/lease, expiry/revocation and current connector authority. Reads and prepared writes are recorded against the delegation. Neither cookie nor mock connector token is accepted as either bearer purpose. Device commands cannot create grants, approve, enqueue, register or publish an app.

The existing exact-account/payload approval and durable outbox remain authoritative. A human approves the digest and enqueues it separately; the device can dispatch only its mapped proposal. A committed claim admits one fake-provider POST. Uncertain writes remain quarantined and require GET-only reconciliation. Task/delegation revocation after external dispatch cannot promise cancellation; a lost outcome must be recovered through the existing human connector flow. Human review must fit the paired 30-second running lease; expiry requires a new explicitly reviewed task, never automatic replay.

A validated declarative form-schema proposal is stored privately and immutably. Human fingerprint review imports it as a version in the existing app builder. Preview and local publication remain separate actions; app records never enter preview. No arbitrary code app execution is introduced. `/os/delegations/[task]` exposes local account selection, grant/revoke, schema review and links to the existing publication/connector receipt screens. Production conditional imports remove the integration implementation and local delegation UI. The paired panel is loaded on demand to preserve the unchanged 204,800-byte OS budget; functionality is retained.
