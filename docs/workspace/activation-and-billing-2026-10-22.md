## Reused implementation and missing slice

Existing invitation registration, email-verification/session handling, nine-step resumable onboarding, strict pilot checkout contracts, signed immutable event receipts, version-fenced reconciliation and cancellation already existed. The new slice adds a coherent getting-started/recovery view over those contracts, fixes a pending-entitlement admission gap and extends acceptance through a newly registered invited user's first persistent room/message.

- `/os/start` is accessible through authenticated navigation and the dashboard after onboarding. Existing onboarding completion remains `/os?tour=1`; this adds the next explicit step without changing account activation or membership rules.
- `/api/team-space/start` resolves the actor on every request, returns private/no-store status, current authorised rooms and the existing owner-only billing summary. Members receive no owner billing details or actions. Query parameters and browser storage never supply identity or entitlement.
- Billing return/cancel URLs now go to this status view. A return explains its uncertainty; it never marks payment successful. Failure clears displayed status and offers a read-only retry. The only access state comes from the server. Existing unassigned workspaces explicitly retain their prior membership-scoped access and are not relabelled paid.
- Current server-owned checkout metadata preserves the original request ID/setup choice after reload, restricted by the existing original-requester/current-tenant/fresh-MFA RLS policy. Saved redirect URLs and provider secrets are not returned by the recovery summary. Expired attempts require operator reconciliation; no automatic replacement checkout or changed setup request is offered.
- Local simulation controls remain explicitly synthetic. Pending provider bindings cannot be replaced with fixture activation. Runtime checkout validation still requires separately configured test-mode provider credentials and an HTTPS origin; it is not weakened to accept the local fixture.
