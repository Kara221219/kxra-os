Distinct unexpired pending invitation emails reserve seats unless already represented by a membership identity. Existing last-owner/security-role controls are unchanged.

## Synthetic lifecycle and work fences

Only a verified local fixture principal in the guarded loopback environment, through `kxra_app` and current fresh MFA owner authority, may call the simulation API. The server sets transaction-local `request.kxra.execution_mode`; bodies, JWT user metadata and profile provider tags do not set it. Hosted/nonfixture execution is denied. No credential, provider object or access grant is created outside disposable fixtures.

Manual synthetic events: ACTIVATE, RENEW, PAST_DUE, RECOVER, PAUSE, RESUME, CANCEL_AT_END, CANCEL_NOW and RECONCILE. Each stores an actor/current-tenant-bound nonce, exact expected version and immutable receipt. Replays return the recorded result; changed payload/version conflicts. Renewing after cancellation-at-end is denied. Periods use PostgreSQL calendar-month arithmetic and fixed minor-unit prices; models perform no financial arithmetic.

Current entitlement checks period expiry independently of a wake-up/reconciliation event. Cancellation-at-end preserves access only until that exact end. Immediate cancellation/pause/past-due/expiry block pilot workspace admissions (rooms, agents/messages/tasks, drafts and conversion work); history remains readable. Draft admission/publication and billing transitions share the organisation lock so a committed cancellation cannot be bypassed by a late publication. Existing queued/scheduled work is cancelled/paused on its next authorised drain; no hidden global reaper or hosted worker is installed. Source/identity/room checks still apply independently.

This is **not a Stripe subscription, invoice, signed provider webhook or live payment acceptance**. Existing signed test-Stripe machinery remains separate until a reviewed pilot offer mapping/adapter is implemented with approved secure access. The staging release sequence lists that engineering gate explicitly. Do not label this simulation paid, connected or production-ready.
