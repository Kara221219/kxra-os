# PROJECT-006 — Finance Unfolded YouTube Content Engine

Classification: USER-SUPPLIED INFORMATION for the channel and owner intent; EXTERNAL RESEARCH for dated public observations and platform rules; DECISION for the implemented pipeline and hard stops.

Stage: VALIDATION / PRE-PUBLICATION. Status: LOCAL GOVERNED PIPELINE IMPLEMENTED; PROVIDER DELIVERY DISABLED. Venture and Confidence scores: NOT ASSESSED. No audience, ownership, monetisation, performance, demand or revenue claim is inferred.

Channel supplied by the owner: `https://youtube.com/@finance-unfolded247`. The seed preserves the supplied handle and marks provider authority `UNVERIFIED`. Local tests can record synthetic verification evidence through a private function; this is not YouTube OAuth proof and cannot be carried into production.

Implemented specialist modules: Channel Strategy; Audience & Demand; Topic Backlog; Source Packs; Claim Ledger; Script Versions; Compliance / Red Team; Storyboards; Asset & Music Rights; Voice / Presenter Provenance; Render Queue; Video QA; Thumbnails & Metadata; Publication Approvals; YouTube Uploads; Schedule; Analytics; Content Experiments.

The workspace creates immutable, versioned content packages containing the source pack, claim ledger, script, red-team notes, storyboard, rights, voice/presenter provenance, render manifest, QA and metadata. A different current actor must review the exact package version and SHA-256. Every source, claim, originality, rights, disclosure, compliance, technical-QA, caption and metadata check must pass. Revision supersedes prior approval and disconnecting the channel withdraws existing ready intents.

The final local artifact is an idempotent upload intent with adapter `DISABLED` and delivery state `NOT_SENT`. No OAuth callback, token store, upload, scheduling, analytics ingestion or publication executor exists.

Hard stop: no upload or schedule without an exact current approved package and a currently verified binding. Initial publication and regulated-promotion, sponsorship, advice-like, realistic synthetic-person/event and material-correction cases require human review. A package creator cannot finally approve the same package.

Acceptance evidence: AT-38 and AT-43 pass for the local package, independent review, current binding, disabled intent, revocation and project-isolation boundaries. AT-37 and AT-39 remain partial until real staging OAuth, delivery, provider reconciliation and revocation tests exist.
