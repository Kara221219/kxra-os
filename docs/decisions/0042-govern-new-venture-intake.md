# ADR 0042 — Govern the 30 September venture intake as Projects 008–012

Status: Accepted for implementation on 30 September 2026.

## Context

The owner supplied five venture ideas: wall printing, Manchester short-stay property services, a clear-aligner dental venture, online product commerce and an AI-assisted dealership sales workflow. The owner said wall printing already existed, but the tracked repository and private Genesis project register contained no canonical wall-printing project.

## Decision

Create PROJECT-008 through PROJECT-012 in the order supplied, placing wall printing first to preserve the owner's prior-intake statement. Record all five as owner-supplied concepts with null scores, no budget, no partner assignment, no public visibility, no product-creation authority and no live execution.

Give each project 18 common workspace modules, eight specialist evidence modules and one explicit gate. External social references remain unverified evidence. Regulatory and vendor research informs blockers but does not prove viability. Financial arithmetic remains deterministic and evidence-bound.

No supplier message is sent, no property is listed, no patient is contacted, no product is advertised and no dealer lead is messaged by this decision.

## Consequences

The canonical portfolio contains twelve projects. Hosted staging requires migration 0074 and a new canonical seed import before the five records appear. Existing project permissions and RLS apply unchanged; a partner sees a new project only after a separate active membership is granted.
